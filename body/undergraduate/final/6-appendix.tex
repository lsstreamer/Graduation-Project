            \setlength{\itemsep}{0pt}
            \item 游戏开发人员
            \item 三维建模师
            \item 影视特效师
            \item 学生
            \item 自媒体创作者
            \item 其他
        \end{itemize}

        \item 您是否具备三维建模相关经验？
        \begin{itemize}
            \setlength{\itemsep}{0pt}
            \item 专业从业者
            \item 有一定经验
            \item 初学者
        \end{itemize}

        \item 您通常使用哪些三维软件？
        \begin{itemize}
            \setlength{\itemsep}{0pt}
            \item Blender
            \item Maya
            \item 3ds Max
            \item Unreal Engine
            \item Unity
            \item 其他
        \end{itemize}

        \item 您平均每周使用三维工具的频率是多少？

            \item 偶尔使用

    \subsubsection{需求与痛点调研}

    \begin{enumerate}
        \setcounter{enumi}{8}

        \item 您在使用现有纹理生成工具时，
        遇到过哪些问题？

        \item 您是否遇到过以下情况？

            \setlength{\itemsep}{0pt}
